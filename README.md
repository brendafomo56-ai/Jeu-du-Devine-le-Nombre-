# Jeu du Devine le Nombre

Un petit jeu interactif développé en **Python** où l'utilisateur doit deviner un nombre secret choisi aléatoirement par l'ordinateur.

## 📝 Règles du jeu
* L'ordinateur choisit un nombre mystère entre **1 et 100**.
* À chaque tentative, le programme indique si le nombre secret est **plus grand** ou **plus petit**.
* Le jeu se termine lorsque l'utilisateur trouve le bon nombre.

## 🚀 Comment lancer le projet
1. Assurez-vous d'avoir installé [Python](https://python.org).
2. Lancez le script depuis votre terminal avec la commande suivante :
```bash
python main.py
```
*(Remplacez `main.py` par le vrai nom de votre fichier Python s'il est différent)*
